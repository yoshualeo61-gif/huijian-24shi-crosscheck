# 08 研究方向与相关工作

这份文档回答一个问题：**这个仓库离一篇论文还差什么。**

写给将来回头看这个项目的人（包括作者自己），以及任何要评估它的人。
结论先放前面：**工具不是论文。** 现在有的是一件制成品加一个个案，
不是一个问题加一个答案。

---

## 一、工具不是论文

最弱的框架是「我做了一个二十四史交叉比对工具」。那是一篇软件论文，
或者方法章里的一节。

最强的框架，是这个项目做到了而数字人文领域极少有人做的一件事：
**它否证了自己最响的信号，并且把结果写了出来。**

- `僅見於` 置换检验 p = 1.000（README「当前状态 v0.2.6」）
- 24 人里 19 人只见于一部书，交叉比对无从进行
- 逐字校验闸对现代白话污染**完全无效**——译文确实逐字在 chunk 里
- 基线恰恰在头条发现所依赖的那几部书上无法成立

于是研究问题大致是：

> **史书的讳饰能不能被计算地检出——以及凭什么标准我们才算知道它被检出了？**

后半句才是贡献所在。**那些负面结果不是交稿前要清理掉的难堪，
它们就是发现本身。**

另一块真正新的东西是**独立性建模**：`源流關係`、`孤證`、`同修`、
`同書異志`（见 [03-实现说明](03-实现说明.md)）。这是把传统考据学的
史源批判形式化成机器可核验的关系，而它纠正了朴素的平行段落研究会犯的
一个实质错误：**把唐修的删削派生本当成它所删削那部书的第二个证人。**
这条批判能推广到中国史以外，所以它够得上一篇论文的体量，而不只是一个个案。

## 二、相关工作：动手之前必须先查

这一节比本文档其余部分都重要。

| 既有工作 | 是什么 |
|---|---|
| **CBDB** 中国历代人物传记资料库（哈佛／北大／中研院） | 已从中国历史文献中大规模抽出结构化的人物资料 |
| **MARKUS** | 古汉语文本的半自动标记 |
| **ctext.org** 中国哲学书电子化计划 | 古汉语语料 |
| 文本复用／平行段落检测 | 二十四史上已有研究 |
| 异文研究 | 校勘学传统课题 |

**二十四史的平行段落检测并不新。** 撞上这些工作之后还站得住的是三样：

1. **不对称**——不是「这两段相合」，而是「一方记其死，另一方沉默，
   而它在附近还记了别人的死」。
2. **独立性纠正**——派生本不是第二个证人；同一次修史工程出的书，
   其相合不如各自独立成书者有力。
3. **否证方法**——拿置换检验去打自己的信号，并接受结果。

**CBDB 还可能直接解决本项目一个未决的缺口：**人名归一，
包括《魏书》作「刘晣」而《梁书》作「邓晣」（同官同事）这类姓氏异文——
现在的后缀匹配归一法对它无能为力（见 [06-已知局限](06-已知局限.md)）。

> 以上条目系凭记忆列出，**未经核对**。开工前自行确认各项目的现状与范围。

## 三、答辩会被攻击的地方

1. **「你的研究问题是什么？」** 目前看仓库答不出来。
2. **「精度多少？」** 未测。**这一条最致命。**
3. **「你的发现有哪一条是新的？」** 知异索引是空的，所以不能声称——
   README 自己就禁止这么做。
4. **「你最主要的信号没通过自己的置换检验，那还剩什么？」**
   需要一个正面的回答，不只是诚实。
5. **「这些阈值凭什么？」** 全部权重、词表条目都是手定且明说未经验证。
6. **「n = 1。」** 一个案例（郁洲）、一个时代、一条头条发现。

第 2、3 条不是研究难题，是**工作量**。这是好消息。

## 四、优先顺序

1. **标注。** 先两人各标 30 条把指南定下来并算 κ，再标 150 条。
   这把「未测」变成一个数字，需要的是几天，不是几个月。
   脚手架早就做好了：`python biaozhu.py sample work/ -n 30`。
2. **从考异文献建知异索引**——钱大昕《廿二史考异》、王鸣盛
   《十七史商榷》、赵翼《廿二史劄记》。这件事本身就是一项实在的
   学术贡献，而且它是**唯一**能让「新发现」这种话说得出口的前提，
   体量足够当一章。
3. **挑一个史学问题用工具回答它。** 宋／辽／金 是本语料最厚的一段
   （《宋史》列传 255 卷对《金史》73 卷），也是工具现在最强的一段
   （`python huijian.py cover`）。
4. **然后**才写方法章。

## 五、一句最要紧的提醒

**这个工具已经过了「加功能还有回报」的那个点。**

继续改工具是愉快的，坐下来标 150 条是枯燥的。而下一步真正的进展
只在测量里。`biaozhu.py` 把抽样与统计都做好了，缺的只是有人去标。

如果有导师说那些负面结果是发表前要先解决掉的问题，那是一个关于
**适配度**的信号——在计算人文的方法学语境里，它们恰恰是最好的材料。
