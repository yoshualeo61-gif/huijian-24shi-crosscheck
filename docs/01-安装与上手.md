# 01 · 安装与上手

## 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| Python | 3.9 以上 | 用到了 `re` 的 lookbehind，3.8 也行但没测过 |
| git | 任意版本 | 只用来 clone 语料 |
| 磁盘 | 约 600MB | 原始仓库 250MB ＋ 转换后文本约 120MB |
| API key | Anthropic | 只有 `run` 需要；`search` 和 `dossier` 不需要 |

Windows 用户注意：语料的目录名和文件名全是中文，PowerShell 下正常，但如果用 Git Bash 可能遇到编码问题，建议直接用 PowerShell 或 WSL。

## 安装

```bash
pip install -r requirements.txt
```

只有一个依赖 `opencc-python-reimplemented`，用于繁简自动扩展。

**不装也能跑**，只是 `search 郁洲` 就不会自动带上 `鬱洲`，你得手工 `--also 鬱洲`。程序会在 stderr 提示。

## 设置 API key

```bash
# macOS / Linux
export ANTHROPIC_API_KEY=sk-ant-...

# Windows PowerShell
$env:ANTHROPIC_API_KEY="sk-ant-..."
```

想让它持久化，写进 `~/.bashrc` 或 `~/.zshrc`。

**不要把 key 写进代码里再提交到 git。**

## 第一步：下载语料

```bash
python huijian.py fetch
```

这一步做三件事：

1. `git clone --depth 1` 拉取 [hunterhug/china-history](https://github.com/hunterhug/china-history)
2. 把 HTML 转成纯文本，剥掉网页外壳
3. **排除 621 个「译文」文件**（现代白话翻译，不能混进文言抽取）

跑完会打印一张表：

```
書       立場       卷           字
宋史     元修      471   4,980,100
汉书     漢修      349   4,538,680
明史     清修      318   3,346,747
...
合計            2413  22,050,000
```

表中數字僅為示意。**權威數字是 `fetch` 當場打印的那一行**——
上游倉庫隨時可能增刪，過去的統計（含 `互見_介紹.pptx` 裡的 3,034 卷 / 3,021 萬字）
含現代白話譯文，已不適用。

**耗时约 2–5 分钟**，取决于网速。中断了重跑即可，clone 会跳过。

## 第二步：纯检索（不花钱）

```bash
python huijian.py search 郁洲 --also 郁州 田横岛
```

这一步完全本地，不调 API。它会：

- 用 opencc 把 `郁洲` 扩展成 `郁洲`、`鬱洲`
- 加上你 `--also` 给的别名
- 扫全部语料（约 2,413 卷），按立场分组打印命中段落

**先跑这一步。** 如果检索结果太少或者全是无关的，说明检索词不对，这时候调 API 是浪费钱。

## 第三步：试跑（控成本）

```bash
python huijian.py run 郁洲 --dry-run
```

`--dry-run` 只列出将要发出的请求，**不实际调用 API**。你会看到类似：

```
檢索詞: 郁洲、鬱洲
命中 29 段，開始抽取…
  [1/18] 三国志·魏书_袁张凉国田王邴管传  (401字)
  [2/18] 南史·南史_-卷一  (802字)
  ...
```

数一下有多少次调用，估算成本。文言文大致一字一 token，一次 400–800 字的请求很便宜。

确认没问题后加 `--limit` 小跑一次：

```bash
python huijian.py run 郁洲 -o out/ --limit 10
```

## 第四步：正式跑

```bash
python huijian.py run 郁洲 -o out/
```

产出两个文件：

- `out/郁洲_report.txt` — 人读的报告
- `out/郁洲_findings.json` — 机器读的结果，喂给 `duizhao.py` 或标注界面

## 第五步：事件层

```bash
python duizhao.py align out/郁洲_findings.json
```

把同一事件在不同立场史书中的叙述并排摆出，标出纪年歧异和立场用语对立。

## 第六步：标注界面

`ui/shiyuan_reader.jsx` 是一个 React artifact，需要在支持 artifact 的环境里运行（Claude.ai 里直接粘贴即可）。

它的用途不是重跑分析，而是**人工核定**：把 `samples/` 里的史料贴进左右两栏，跑一遍，然后用「核实 / 存疑 / 否定」三个按钮逐条标记，最后导出 JSON。

那份导出就是金标准的雏形。详见 [05-标注指南模板](05-标注指南模板.md)。

## 验证安装是否正常

```bash
# 应该输出 513 / 513 / 475
python duizhao.py eras 延昌二年 天监十二年 元徽三年

# 应该输出一组「垣崇祖」的对照
python duizhao.py align samples/测试用_findings.json -t 3
```

两条都对，说明装好了。
