# 05 · 标注指南模板

这份文档是**给你填的**，不是填好的。

**抽样与计分现在有工具了**（`biaozhu.py`），所以你要填的只剩判断本身：

```bash
python biaozhu.py sample work/ -n 30         # 第一轮：预试，两人各标一份
python biaozhu.py score work/ --second 乙.json  # 比 κ、改指南
python biaozhu.py sample work/ -n 150        # 第二轮：正式
python biaozhu.py score work/                # 出精度 + 置信区间
```

工具负责分层抽样、Wilson 置信区间、Cohen's κ；**判断仍然由人下**，
这一点不会变也不该变。

## 为什么需要标注

现在系统里所有参数——锚定阈值、立场词表、终局互斥集——都是拍脑袋定的。
没有标注，你无法知道：

- 抽取的准确率是多少
- 哪条规则靠谱、哪条该扔
- 阈值该定在几

**标注是把「感觉还行」变成「准确率 85%」的唯一途径。**

样本量要多少：n=30 时精度的 95% 区间宽约 ±15 个百分点，只够对指南；
n=150 且观测精度 0.9 时区间约 [0.84, 0.94]，**够分辨「能用」和「不能用」**，
而这是目前唯一需要分辨的事。再往上收窄要几百条，先不必。

## 三条轨道，可标注性根本不同

这是本文档原先没有分开、而实际必须分开的一件事：

| 轨 | 问什么 | 性质 | 预期 κ |
|---|---|---|---|
| **A 抽取精度** | 原文是否支持这条记载？ | **可核验**，不是解释 | 应该很高（> 0.8） |
| **B 信号效度** | reading：旗标是否正确描述记载？ | 可核验 | 应该高 |
| | interpretation：讳饰是否最佳解释？ | **解释性** | 低（0.27–0.32 量级） |
| **C 负对照** | 这条拦得对不对？ | 可核验 | 应该很高 |

**先做 A 轨。** 它出的是头条数字（「抽取精度 X%，95% CI […]」），
成本最低，而且两个细心的读者几乎总能一致——因为问的是「原文有没有这么写」，
不是「这意味着什么」。判断时只看 evidence 那一句，不要去回想史实：
测的是抽取，不是你的学识。

**B 轨的 interpretation 一层，低 κ 是预期结果，不是失败。** 真判出
κ 0.3，那就是这个维度的上限，该做的是在结论里承认它，不是反复改指南。
拿不定主意就填 `undecidable`——**undecidable 的比例本身就是有用的结果**。

**C 轨以前完全没人量。** 拦截率一直有报（「拦下 N 条伪引」），
但「拦得对不对」没量过。误拦是召回的净损失：引文其实在原文里，
却因为切块或接缝的缘故被闸门丢掉。`verify` 现在把拦截记录存进
`work/dropped.json`，C 轨就从这里抽。

## 两轮流程

```
第一轮：读 30 段 · 两人独立标
          ↓
       比对分歧 · 写指南 · 砍掉对不上的类型
          ↓
第二轮：读 200 段 · 按修订后的指南
          ↓
       算准确率 · 调参数
```

**第一轮的价值远大于第二轮。** 很多人跳过第一轮直接标两百段，
最后发现两人标的东西不一致，全废。

## 关键：必须两个人

一个人标出来的东西，他的判断就是标准，没人知道这个标准合不合理。

两人独立标同一批，然后算 **Cohen's κ**（标注者一致性）。这个数有双重作用：

- 测标注质量
- **测这个维度本身可不可做**

参考值：κ > 0.7 说明任务良定义；κ < 0.4 说明连人类都对不上，
**这个维度应该从系统里删掉**，不要指望机器做人做不到的事。

已有实证：文本表面的维度（形式、源标记）κ 能到 0.71–0.77；
需要重建意图的维度（功能、立场）κ 只有 0.32 和 0.27。

## 标什么

用 `ui/shiyuan_reader.jsx` 界面，对每一条系统输出标记：

| 标记 | 含义 |
|---|---|
| 核实 | 引文属实，且系统的判定成立 |
| 存疑 | 引文属实，但判定是否成立不确定 |
| 否定 | 引文有误，或判定明显不成立 |

导出的 JSON 里每条会带上 `人工判定` 字段。

## 算准确率

标完之后：

```
准确率 precision = 标为「核实」的条数 / 系统输出总条数
召回率 recall    = 系统找到的 / 人工通读找出的全部
```

**召回率需要人工通读同一批史料并独立列出所有应有条目**，比准确率费事得多。
第一轮可以只算准确率。

## 最后

这份标注数据是**你自己的资产**。工具会过时，模型会换代，
但一份两个人标过、有 κ 值、附标注指南的语料，五年后还能用，
而且是可以署名发表的东西。

代码谁都能重写，标注数据重做一遍要几十个工时。
